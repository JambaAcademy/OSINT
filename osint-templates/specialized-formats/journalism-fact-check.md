# Journalism Fact-Check Report

## Purpose Statement

This template supports journalists and fact-checkers in documenting the verification process for a specific claim, image, video, or piece of viral content, using open-source intelligence methods. It emphasizes transparency of method so that the resulting published verdict can be independently scrutinized by readers.

## 4. Verification Methodology

### 4.1 Image/Video Verification (If Applicable)

- [ ] Reverse image search conducted to check for earlier or alternate use of the image/video
- [ ] Metadata examined where available (noting that metadata is frequently stripped by platforms and its absence is not itself evidence of manipulation)
- [ ] Geolocation attempted using visible landmarks, signage, shadows, or other environmental cues
- [ ] Chronolocation attempted using visible environmental cues (weather, foliage, shadow angle) to estimate time of capture
- [ ] Original source of the media identified, where possible
