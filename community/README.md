# Community

## Overview

This directory contains resources supporting the community around this repository: templates for submitting contributions, discussion facilitation guidance, event planning materials, and a curated list of external OSINT learning resources beyond this repository itself.

---

## Subfolders

| Subfolder | Description |
|---|---|
| [`contributions/`](contributions/README.md) | Issue and submission templates for proposing changes to this repository |
| [`discussions/`](discussions/README.md) | Discussion facilitation guidance and a community FAQ |
| [`events/`](events/README.md) | Planning materials for workshops, webinars, and meetups |
| [`resources/`](resources/README.md) | Curated list of external OSINT learning resources, communities, and publications |

---

## Getting Involved

- **To contribute a change:** see [CONTRIBUTING.md](../CONTRIBUTING.md) at the repository root, and use the issue templates in `contributions/` to propose your change before submitting a pull request for anything non-trivial.
- **To ask a question or start a discussion:** see `discussions/README.md` for guidance on using the repository's discussion space effectively.
- **To organize a community event:** see `events/README.md` for planning templates.
- **To go deeper than this repository covers:** see `resources/README.md` for external books, training providers, communities, and conferences.
