# Getting Started

## Overview

This section orients newcomers to OSINT methodology and this repository's structure. See `first-investigation-walkthrough.md` for a complete, step-by-step walkthrough of a beginner's first investigation using this repository's templates and tools.

---

## Recommended Learning Path

1. **Read this repository's root [README.md](../../README.md)** for the overall structure and purpose.
2. **Read `osint-templates/README.md`** to understand the template library and how to choose the right template for your investigation type.
3. **Complete `first-investigation-walkthrough.md`** (this folder) using a low-stakes practice subject (see the training scenarios in `../training-materials/`).
4. **Review `osint-templates/operational-planning/`** in full — every investigation should begin with a collection plan, legal compliance check, and risk assessment, regardless of how straightforward it seems.
5. **Bookmark `../reference-guides/`** for quick lookups during active work.

## Common Beginner Mistakes

- **Skipping the collection plan.** Jumping straight into searching without defining specific questions leads to unfocused, incomplete investigations.
- **Treating every source as equally reliable.** A single anonymous forum post and a government registry filing are not the same kind of evidence.
- **Scope creep.** Following interesting tangents without checking whether they serve the original investigative objective.
- **No documentation until the end.** Trying to reconstruct sources and dates from memory when writing the final report, rather than logging as you go.
- **Ignoring the legal/ethical review step** because the investigation "seems obviously fine." Complete the checklist anyway; it takes a few minutes and catches real issues.
