# Events

## Overview

This section provides planning materials for community-organized workshops, webinars, and meetups built around this repository's content. See `workshop-planning-template.md` for a structured planning document covering logistics, curriculum, and facilitation guidance.

---

## Event Format Suggestions

| Format | Typical Length | Best For |
|---|---|---|
| Introductory workshop | 2-3 hours | Walking newcomers through `documentation/getting-started/first-investigation-walkthrough.md` hands-on |
| Methodology deep dive | 1-1.5 hours | A focused session on one topic, e.g., the correlation methodology in `documentation/advanced-techniques/` |
| Tool showcase | 45-60 minutes | Demonstrating a specific tool category from `osint-tools/` with live examples |
| Case study discussion | 45-60 minutes | Working through one of the case studies in `documentation/case-studies/` as a group exercise |
| Office hours / Q&A | 30-60 minutes | Open, informal troubleshooting and methodology discussion |

---

## Using the Workshop Planning Template

`workshop-planning-template.md` walks through defining your audience and objectives, building an agenda, preparing materials, and running the session, with built-in reminders to keep any hands-on exercises within the ethical practice guidance in `documentation/training-materials/README.md`.

---

## General Guidance for Organizers

- **Always use practice scenarios, not real subjects,** for any hands-on portion of an event, per `documentation/training-materials/README.md`.
- **State the repository's Code of Conduct expectations explicitly at the start of any hands-on session**, since a workshop setting can create pressure to demonstrate on a "real" example that isn't appropriate.
- **Record sessions only with clear participant notice and consent**, and avoid capturing any participant's screen if they are working with anything sensitive during a hands-on exercise.
