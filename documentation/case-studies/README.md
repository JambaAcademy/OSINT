# Case Studies

## Overview

This section contains fictionalized, illustrative case studies demonstrating how this repository's templates and tools work together in a complete, realistic investigation. All names, companies, and identifying details in these case studies are fictional; any resemblance to real persons or entities is coincidental. Case studies are designed to show methodology in context, not to serve as templates to copy directly — use the actual templates in `osint-templates/` for real work.

## How to Use These Case Studies

- Read through a case study's narrative first, then trace each step back to the specific template or tool referenced to see how it fits into the broader workflow described in `../getting-started/first-investigation-walkthrough.md`.
- Note where the fictional analyst considers and rules out alternative explanations — this is deliberately included in every case study, consistent with the methodology in `../advanced-techniques/multi-source-correlation-methodology.md`.
- Notice what each case study's analyst does *not* do (e.g., avoiding disproportionate scope, respecting the boundaries in `osint-tools/people-investigation/README.md`) as much as what they do.
