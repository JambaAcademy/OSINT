# Documentation

## Overview

This directory contains narrative and educational documentation that complements the structured templates in `osint-templates/` and the tool directories in `osint-tools/`: onboarding material for newcomers, methodology guides for experienced analysts, legal and ethical reference material, real-world case studies, training exercises, and condensed quick-reference guides.

---

## Subfolders

| Subfolder | Description |
|---|---|
| [`getting-started/`](getting-started/README.md) | Onboarding guides and a first-investigation walkthrough for newcomers |
| [`advanced-techniques/`](advanced-techniques/README.md) | Expert-level methodology for correlation, pivoting, and multi-source synthesis |
| [`legal-and-ethics/`](legal-and-ethics/README.md) | International legal framework reference and ethical decision-making guidance |
| [`case-studies/`](case-studies/README.md) | Anonymized, fictionalized case studies demonstrating end-to-end methodology |
| [`training-materials/`](training-materials/README.md) | Practice exercises and training scenarios for skill development |
| [`reference-guides/`](reference-guides/README.md) | Condensed quick-reference cards for use during active investigations |

---

## How This Directory Relates to the Rest of the Repository

- **`osint-templates/`** provides the structured documents you fill in during and after an investigation.
- **`osint-tools/`** provides curated directories of tools and working scripts you use during collection and analysis.
- **`documentation/`** (this directory) explains *how* and *why*: the methodology, judgment calls, and context that make the templates and tools effective in practice.

New users should generally start with `getting-started/`, refer to `reference-guides/` during active work, and consult `advanced-techniques/` and `case-studies/` as they build experience.
