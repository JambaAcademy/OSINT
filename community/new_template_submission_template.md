## Content Standards Checklist

Confirm the following before submitting, per [CONTRIBUTING.md](../../CONTRIBUTING.md):

- [ ] File naming follows the lowercase-hyphenated convention used elsewhere in the same folder
- [ ] For a new template: includes an executive summary block, numbered major sections, a legal/ethical considerations section, and a version-control footer
- [ ] For a new tool entry: includes a one-line description, primary use case, and licensing/cost model
- [ ] For a new script: includes a module-level docstring, uses only publicly accessible or properly authorized data sources, has no hardcoded credentials, and has been tested against real or realistic sample data
- [ ] No real personal data, credentials, or proprietary material included anywhere in the submission
- [ ] Content reviewed against the Legal and Ethical Requirements in [CONTRIBUTING.md](../../CONTRIBUTING.md)
- [ ] Links checked and confirmed working as of the submission date
