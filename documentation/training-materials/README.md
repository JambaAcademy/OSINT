# Training Materials

## Overview

This section provides practice exercises and training scenarios for developing OSINT skills in a safe, low-stakes context. See `practice-exercises.md` for a structured set of exercises ranging from beginner to advanced, each designed to be completed using only publicly available information about deliberately chosen, low-sensitivity subjects.

## Guidance for Practicing Safely and Ethically

- **Practice on organizations and public entities, not private individuals**, wherever an exercise allows it. Where an exercise calls for practicing a person-focused technique, practice on your own public information, a consenting colleague's, or a well-known public figure's already-extensively-public information, never a private individual who has not consented.
- **Complete the operational planning templates even for practice.** Building the habit of using `osint-templates/operational-planning/` for low-stakes practice makes it automatic for real investigations.
- **Time-box your practice.** Set a specific time limit for each exercise to build efficient habits rather than open-ended searching.
- **Review your work against the relevant template's structure**, not just against whether you "found the answer," since the goal is building a repeatable, defensible methodology, not just curiosity-driven searching.
