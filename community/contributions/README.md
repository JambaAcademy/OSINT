# Contributions

## Overview

This section provides structured templates for proposing changes to this repository: bug reports, feature requests, and new template/tool submissions. Using these templates helps maintainers triage and respond to contributions efficiently. See [CONTRIBUTING.md](../../CONTRIBUTING.md) at the repository root for the full contribution process these templates support.

---

## Available Templates

| Template | Use When |
|---|---|
| [`bug_report_template.md`](bug_report_template.md) | Reporting a broken link, factual error, or formatting issue in existing content |
| [`feature_request_template.md`](feature_request_template.md) | Proposing a new template, tool category, or documentation topic not yet covered |
| [`new_template_submission_template.md`](new_template_submission_template.md) | Submitting a complete new investigation report template or tool directory for review |

---

## How to Use These Templates

1. Copy the relevant template's content into a new GitHub issue (or, if your fork's workflow uses a different issue tracker, adapt accordingly).
2. Fill in every section — incomplete issues take longer to triage and are more likely to be deprioritized.
3. Search existing issues first to avoid duplicates, per [CONTRIBUTING.md](../../CONTRIBUTING.md).
