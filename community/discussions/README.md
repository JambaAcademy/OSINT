# Discussions

## Overview

This section provides guidance for using this repository's community discussion space effectively, and a frequently-asked-questions reference for common questions about the repository's scope, methodology, and policies. See `community-faq.md` for the FAQ itself.

---

## Discussion Categories

If your platform's discussion space supports categories, we recommend organizing around:

| Category | Use For |
|---|---|
| Q&A | Specific questions about using a template, tool, or technique |
| Methodology | Broader discussion of OSINT approach, technique tradeoffs, and best practices |
| Show and Tell | Sharing how you've used or adapted repository content (without disclosing details of a real, sensitive investigation) |
| Ideas | Early-stage feature ideas not yet ready for a formal feature request (see `../contributions/feature_request_template.md`) |

---

## Discussion Guidelines

- Keep discussion consistent with this repository's [Code of Conduct](../../CODE_OF_CONDUCT.md): no real, identifiable private individuals as discussion examples, no requests for help investigating a specific real person without a clearly stated, legitimate, proportionate purpose.
- Prefer opening a specific issue (see `../contributions/`) over a discussion thread for anything that is clearly a bug or a concrete, ready-to-propose feature; use discussions for genuinely open-ended questions or ideas.
- When asking a methodology question, include enough context (what template/tool you're using, what you've already tried) for others to give a useful answer efficiently.
