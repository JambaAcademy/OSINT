# Resources

## Overview

This section curates external OSINT learning resources beyond this repository: books, training providers, practitioner communities, conferences, and newsletters. See `external-learning-resources.md` for the full curated list.

---

## How This Differs from `documentation/`

- **`documentation/`** contains original educational content maintained as part of this repository.
- **`resources/`** (this folder) points outward to the broader OSINT community's own publications, training, and gathering places.

---

## Contribution Note

If you know of a high-quality external resource not yet listed, propose it via `../contributions/feature_request_template.md`. To keep this list genuinely useful rather than exhaustive, we prioritize resources with a sustained track record and genuine educational value over comprehensiveness.
